# BRAND ICONIC — MASTER WORKFLOW MAP
## How the Entire System Operates

---

## THE FOUR CORE WORKFLOWS

```
WORKFLOW 1: MARKET → OFFER → VALIDATE
(Do this before anything else. Must complete fully.)

WORKFLOW 2: ATTRACT → QUALIFY → CLOSE
(Sales engine. Runs continuously after Workflow 1.)

WORKFLOW 3: ONBOARD → DELIVER → RETAIN → EXPAND
(Client engine. Runs for every signed client.)

WORKFLOW 4: MEASURE → LEARN → ITERATE
(Intelligence loop. Runs weekly on all workflows.)
```

## WORKFLOW 1: MARKET → OFFER → VALIDATE

**Purpose:** Discover what the market actually wants and design the simplest offer that sells.
**Timeline:** Weeks 1-3 (before any outreach)
**Skills used:** `/market-research` → `/persona-map` → `/competitor-analysis` → `/pricing-strategy` → `/offer-design` → `/validate-offer`

```
START
  │
  ▼
[/market-research]
  Research 3 potential ICP segments
  Output: 3 market research reports
  Gate: All 3 reports complete with confidence >MEDIUM
  │
  ▼
[/persona-map]
  Map 1-2 personas per segment
  Output: 2-4 persona maps with language banks
  Gate: Each persona has 10+ real data points
  │
  ▼
[/competitor-analysis]
  Analyze top 8-10 competitors
  Output: Individual reports + landscape overview
  Gate: Positioning gap identified
  │
  ▼
[/pricing-strategy]
  Research market rates + value calculation
  Output: Pricing research report
  Gate: Price range defined with evidence
  │
  ▼
[/offer-design]
  Design 1 minimum viable offer
  Gate: All prerequisite research files present (HARD GATE)
  Output: Offer design doc with MVP version
  │
  ▼
[/validate-offer]
  Stage 0: Desk research validation
  Stage 1: 5-10 problem conversations
  Stage 2: 5-10 solution conversations
  Stage 3: Price conversations
  Stage 4: First paid commitment
  Gate: At least 1 paying client before scaling
  │
  ▼
WORKFLOW 1 COMPLETE → Begin Workflow 2 at scale
```

## WORKFLOW 2: ATTRACT → QUALIFY → CLOSE

**Purpose:** Predictable pipeline of qualified leads.
**Timeline:** Starts Week 3, runs continuously.
**Skills used:** `/sales-copy` → `/email-sequence` → `/content-brief`

```
ATTRACT
  │
  ├── [LinkedIn Content] → /content-brief → /sales-copy
  │     5 posts/week (Agent 11)
  │     Goal: Profile visits → connection requests
  │
  ├── [Outbound Outreach] → /sales-copy
  │     Cold DMs: 20-50/day
  │     Cold Emails: 50-100/day
  │     Using language from persona maps
  │
  └── [Referral System] → /email-sequence (referral ask)
        Activated after first 3 clients
  │
  ▼
QUALIFY
  │
  [BANT+ Filter — Agent 08]
  Budget confirmed → Authority confirmed → Need confirmed → Timeline confirmed → Fit confirmed
  If any fail: disqualify immediately, move on
  │
  ▼
  [Discovery Call]
  Ask > Tell
  Document pain in their exact words
  Confirm they are the ICP
  │
  ▼
CLOSE
  │
  [Proposal] → /sales-copy (proposal narrative format)
  Sent within 24 hours of discovery call
  3-tier pricing always
  │
  ▼
  [Follow-up Sequence] → /email-sequence (post-call type)
  3-email sequence
  Addresses specific objection raised on call
  │
  ▼
  [Contract + Deposit]
  Validation Stage 4 complete: money received
  → Trigger Workflow 3
```

## WORKFLOW 3: ONBOARD → DELIVER → RETAIN → EXPAND

**Purpose:** Turn new clients into long-term, high-value relationships.
**Timeline:** Starts on contract signing, perpetual.
**Skills used:** `/onboard-client` → `/brand-audit` → `/client-report`

```
ONBOARD (Week 1)
  │
  [/onboard-client skill]
  ├── Welcome email
  ├── Kick-off call
  ├── Brand brief completion
  ├── 90-day strategy
  └── Baseline metrics documented
  │
  ▼
DELIVER (Ongoing)
  │
  [Monthly delivery cycle]
  ├── Week 1: Strategy + planning
  ├── Week 2: Core deliverables production
  ├── Week 3: Review + refinement
  └── Week 4: Report + next month planning
  │
  Each deliverable: → Agent produces → QC Agent reviews → Client receives
  │
  ▼
RETAIN (Monthly)
  │
  [/client-report skill]
  ├── Results vs. goals
  ├── Wins highlighted
  ├── Challenges addressed
  └── Next month preview
  │
  [NPS pulse check — 3 questions]
  Score < 7: Immediate escalation call
  Score 7-8: Identify improvement area
  Score 9-10: Referral ask
  │
  ▼
EXPAND (Month 3+)
  │
  [Upsell identification — Agent 13]
  ├── What adjacent service would help them most?
  ├── Propose expansion in monthly report
  └── Referral ask — structured, specific
```

## WORKFLOW 4: MEASURE → LEARN → ITERATE

**Purpose:** Make the system smarter every week.
**Cadence:** Weekly internal review.

```
EVERY FRIDAY:
  │
  ▼
[/client-report (internal version)]
Analytics Agent produces CEO dashboard:
  ├── MRR vs. target
  ├── Pipeline value and movement
  ├── Outreach metrics (sent / replied / booked / closed)
  ├── Content performance (impressions / engagement / leads)
  └── Client health scores (NPS + delivery status)
  │
  ▼
[DECISION TRIGGERS]

If outreach reply rate < 3%:
  → Pull persona maps, rewrite copy, A/B test new approach

If close rate < 15%:
  → Review proposal quality, pricing, objection patterns

If client NPS < 7:
  → Immediate client success escalation

If MRR behind target by >20%:
  → Activate emergency sprint: double outreach volume, review offer
  │
  ▼
[KNOWLEDGE BASE UPDATE]
Document what we learned this week in `/knowledge-base/`
Update agent instructions if patterns emerge
Add new templates if something worked well
```
