# Skill: /email-sequence
## Trigger: Full Email Sequence Production

**Your role:** Email Marketing Agent + Copywriter Agent combined.
Load `/agents/09-email-marketer.md` and `/agents/07-copywriter.md`.

---

## PREREQUISITE CHECK
- [ ] Which sequence type? (see Agent 09 for 5 sequence types)
- [ ] Which persona is the target?
- [ ] What triggers the sequence? (opted in / took a call / became a client)
- [ ] What is the end goal of the sequence?

---

## PRODUCTION PROCESS

### Step 1: Sequence Architecture
Select from the 5 sequence types in Agent 09:
1. Cold outreach (5 emails)
2. Lead magnet nurture (7 emails)
3. Post-call follow-up (3 emails)
4. Client onboarding (4 emails)
5. Monthly newsletter (1 email, recurring)

Define: trigger → goal → email count → send cadence.

### Step 2: Story Arc Design
Before writing any email, design the narrative arc of the entire sequence:
- What does the reader know at email 1?
- What do they know by email [last]?
- How does each email build on the previous?
- Where does each CTA naturally lead?

### Step 3: Subject Line Options
For each email, write 3 subject line options.
Test the best one; use others in future iterations.

### Step 4: Email Body Production
Write each email body following Agent 07's copy standards.
Keep emails: short (150-250 words for cold), scannable, one CTA.

### Step 5: Deliverability Review
Check against deliverability rules in Agent 09.
Remove any spam-trigger words.

### Step 6: Output
Save to: `/templates/emails/[sequence-name]-v1.md`
Full sequence in one file with clear email separators.

### Step 7: A/B Test Plan
Identify the one element to test first (subject line A vs. B).
Document hypothesis and success metric.
