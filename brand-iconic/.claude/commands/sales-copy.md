## PRODUCTION PROCESS

### Step 1: Brief Collection
- Who is this for? (specific persona)
- What is the context? (cold / warm / retargeting)
- What awareness stage? (select from 5 stages in agent 07)
- What is the ONE desired action?
- Any specific angles or hooks to test?

### Step 2: Language Loading
Pull the exact language bank from the relevant persona map.
Every key phrase in the copy should use their words, not ours.

### Step 3: Draft Production
Write version 1 following the appropriate framework from Agent 07.

### Step 4: Self-QC
Run through the copy quality checklist from Agent 07.
If anything fails, fix it before outputting.

### Step 5: Output
Save to `/templates/[type]/[YYYY-MM-DD]_[description]-v1.md`

### Step 6: QC Gate
Flag for `/qc-check` before using with any real prospect.

---

## ANTI-PATTERNS — NEVER WRITE THESE
- "We are a leading provider of..."
- "Our cutting-edge solutions..."
- "We leverage synergies..."
- "We're passionate about..."
- "One-stop shop"
- "Best-in-class"
- "Game-changer"
- "Innovative approach"
- Any generic claim that every competitor could also make

---

## EXAMPLE: Cold LinkedIn DM (for reference only)

```
[First name], I noticed [specific observation about their company/post/situation].

Most [their role]s I talk to are dealing with [specific pain].

We helped [similar company] [specific result] in [timeframe].

Worth a quick chat to see if there's a fit?
```

Total: 4 sentences. Personalized. Specific. Low-friction ask.
Never write longer than this for a cold DM.
